                 Adım Adım Anahtar Bulma Kılavuzu
              
              
5 Anahtar Nasıl Alınır ve Vercel'e Nasıl Girilir?

              
Anahtarları aşağıdaki kutulara yapıştırırsanız, Vercel'e tek seferde toplu yapıştırabileceğiniz formatı otomatik üretir.

            

            
          


          
          

            

              

                1
                
GEMINI_API_KEY

                (WhatsApp sesli mesajlarını Türkçe metne çevirmek için)
              

              
                Google AI Studio'yu Aç
                
              
            

            
    
              
  1. Üstteki Google AI Studio linkine tıklayın ve Google hesabınızla giriş yapın.
    2. 
              
  2. Mavi renkli "Create API key" butonuna basın.
    3. 
              
  3. Size verilen AIzaSy... ile başlayan anahtarı kopyalayıp aşağıya yapıştırın:
    4. 
            

            
          


          
          

            

              

                2
                
GOOGLE_CLIENT_ID & GOOGLE_CLIENT_SECRET

                (Takvim ve Rehber yetkisi için)
              

              
                Google Cloud Console'u Aç
                
              
            

            
    
              
  1. Google Cloud Console'da üstten "New Project" diyerek bir proje açın.
    2. 
              
  2. Sol menüden APIs & Services > Library kısmına girip "Google Calendar API" ve "Google People API" aratıp ikisini de Enable (Etkinleştir) yapın.
    3. 
              
  3. Sol menüden OAuth consent screen sekmesine tıklayın:
                
      
                  
    • User Type: External seçin, uygulama adına "WhatsApp Asistan" yazıp kaydedin.
      • 
                  
    • Test users kısmına kendi Gmail adresinizi ekleyin.
      • 
                
    
              
    4. 
              
  4. Sol menüden Credentials sekmesine geçin > üstten "+ Create Credentials" > "OAuth client ID" tıklayın:
                
      
                  
    • Application type: Web application seçin.
      • 
                  
    • Authorized redirect URIs kısmında "+ Add URI" butonuna basıp tam olarak şunu yapıştırın:
      
                    https://developers.google.com/oauthplayground
                  
      • 
                
    
              
    5. 
              
  5. Create dediğinizde ekrana çıkan Client ID ve Client Secret değerlerini buraya yapıştırın:
    6. 
            

            

              
              
            

          


          
          

            

              

                3
                
GOOGLE_REFRESH_TOKEN

                (Botun her seferinde şifre sormadan takviminize yazabilmesi için)
              

              
                Google OAuth Playground'u Aç
                
              
            

            
    
              
  1. Üstteki OAuth Playground sayfasını açın. Sağ üst köşedeki ⚙️ (Çark / Ayarlar) simgesine tıklayın.
    2. 
              
  2. "Use your own OAuth credentials" kutucuğunu işaretleyin ve 2. adımda aldığınız Client ID ile Client Secret'ı oraya yapıştırıp kapatın.
    3. 
              
  3. Sol alt taraftaki "Input your own scopes" kutusuna şu iki adresi aralarında boşluk bırakarak yapıştırın ve Authorize APIs butonuna basın:
    
                https://www.googleapis.com/auth/calendar.events https://www.googleapis.com/auth/contacts
              
    4. 
              
  4. Kendi Google hesabınızı seçip izin verin. Ardından açılan ekranda "Exchange authorization code for tokens" mavi butonuna tıklayın.
    5. 
              
  5. Size verilen 1//04... ile başlayan Refresh token kodunu buraya yapıştırın:
    6. 
            

            
          


          
          

            

              

                4
                
WHATSAPP_ACCESS_TOKEN & PHONE_NUMBER_ID

                2026 Güncel Meta Paneli
              

              
                Meta for Developers'ı Aç
                
              
            


            

              
              

                
                   Yeni Meta Panelinde Nereden Bulunur?
                
                
    
                  
  1. Uygulamanıza girin, sol menüdeki "Use cases" (Kullanım Alanları) sekmesine tıklayın.
    2. 
                  
  2. Oradaki "Connect with customers through WhatsApp" (veya WhatsApp simgeli kutu) yanındaki "Customize" (Özelleştir) butonuna basın.
    3. 
                  
  3. Açılan alt menüde "API Setup" (API Kurulumu) veya "Quickstart" sekmesini göreceksiniz; ona tıklayın.
    4. 
                  
  4. Sayfanın üstündeki "Generate access token" (Erişim belirteci oluştur) butonuna bastığınızda:
                    
      
                      
    • EAAG... ile başlayan kod ➔ WHATSAPP_ACCESS_TOKEN
      • 
                      
    • Step 1 (From / Gönderen) kutusunun hemen altındaki Phone number ID ➔ WHATSAPP_PHONE_NUMBER_ID
      • 
                    
    
                  
    5. 
                

              


              
              

                
                   Kalıcı (Süresiz) Token Nasıl Alınır? (Önerilen)
                
                

                  API Setup ekranındaki token 24 saatliktir. Botun hiç durmaması için Business Settings üzerinden süresiz token alabilirsiniz:
                

                
    
                  
  1. Meta Business Suite > Ayarlar > Sistem Kullanıcıları sayfasına gidin.
    2. 
                  
  2. "Ekle" (Add) butonuna basıp Admin rolünde bir kullanıcı oluşturun.
    3. 
                  
  3. "Varlık Ekle" (Add Assets) diyerek oluşturduğunuz WhatsApp uygulamasını seçip Tam Kontrol verin.
    4. 
                  
  4. "Yeni Belirteç Oluştur" (Generate New Token) butonuna basın, süreyi "Asla" (Never) seçin ve şu 2 izni işaretleyin:
                    whatsapp_business_messaging, whatsapp_business_management
                  
    5. 
                

              

            


            

              
              
              
            


            
            

              

                
                   Girdiğiniz Token & Phone ID ile Hemen Gerçek Mesaj Testi Yapın:
                
                Meta API Setup > "To" kısmına eklediğiniz kendi numaranızı yazın
              

              

                
                
              

              

            

          


          
          

            

              

                
                5. Son Adım: Vercel'e Yapıştırın & Meta Webhook'u Bağlayın
              

              
            

            

              Adım A (Vercel): Aşağıdaki kutuyu kopyalayıp Vercel projenizde Settings > Environment Variables ekranındaki ilk "Key" kutusuna doğrudan Ctrl+V (Yapıştır) yapın ve Save deyin (ardından Deployments sekmesinden Redeploy yapın):
            

            
GEMINI_API_KEY=AIzaSy_BURAYA_GEMINI_KEY_YAZIN
GOOGLE_CLIENT_ID=BURAYA_GOOGLE_CLIENT_ID_YAZIN
GOOGLE_CLIENT_SECRET=BURAYA_GOOGLE_CLIENT_SECRET_YAZIN
GOOGLE_REDIRECT_URI=https://developers.google.com/oauthplayground
GOOGLE_REFRESH_TOKEN=BURAYA_GOOGLE_REFRESH_TOKEN_YAZIN
WHATSAPP_ACCESS_TOKEN=BURAYA_META_EAAG_TOKEN_YAZIN
WHATSAPP_PHONE_NUMBER_ID=BURAYA_PHONE_NUMBER_ID_YAZIN
WHATSAPP_VERIFY_TOKEN=whatsapp_gizli_anahtar_2026


            

              
                 Adım B (Meta Panelinde Webhook Bağlantısı - Mesajları Yakalamak İçin):
              
              
    
                
  1. Meta panelinde sol menüde API Setup'ın hemen altındaki "Configuration" (Yapılandırma) sekmesine tıklayın.
    2. 
                
  2. Callback URL kutusuna Vercel adresinizin sonuna /api/webhook ekleyerek yazın:
    
                  https://SENIN-VERCEL-SITEN.vercel.app/api/webhook
                
    3. 
                
  3. Verify token kutusuna tam olarak şunu yazın: whatsapp_gizli_anahtar_2026 ve Verify and save butonuna basın.
    4. 
                
  4. Hemen altındaki Webhook fields kısmından Manage butonuna basıp messages satırının yanındaki Subscribe (Abone Ol) kutucuğunu işaretleyin!
    5.
